# Skill: project-context

Gunakan saat merencanakan fitur atau mengambil keputusan produk.

## Langkah

1. Baca `PROJECT_CONTEXT.md` dan bagian relevan `PRD.md`.
2. Pertahankan scope pilot Kecamatan Lhoksukon.
3. Pastikan usulan mendukung penemuan kedai, preferensi kopi, suasana, fasilitas, rating, atau komunitas.
4. Tandai usulan di luar MVP; jangan ubah keputusan tanpa persetujuan.
5. Jawab ringkas dalam Bahasa Indonesia.
