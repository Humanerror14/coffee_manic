# Skill: token-efficiency

Gunakan di setiap sesi coding AI agar konteks hemat.

## Aturan

1. Baca hanya file yang diperlukan.
2. Jangan memuat semua skill; aktifkan skill sesuai pekerjaan.
3. Buat rencana maksimal lima poin sebelum coding.
4. Lakukan patch terarah, bukan menulis ulang file besar.
5. Jangan mengulang konteks di `PROJECT_CONTEXT.md`.
6. Jangan menampilkan seluruh file kecuali diminta.
7. Jangan menambah dependency/abstraksi tanpa alasan.
8. Rangkum file berubah, cara menjalankan/test, dan pekerjaan tersisa.
9. Perbarui `PROJECT_STATUS.md` jika status berubah.
