# Skill: backend-flask

Gunakan saat membuat API atau business logic.

## Aturan

1. Gunakan Flask application factory dan blueprint.
2. Gunakan prefix `/api`.
3. Pisahkan route, model, service, dan validasi saat kebutuhan berkembang.
4. Gunakan SQLAlchemy; validasi input di server.
5. Gunakan HTTP status code dan format error konsisten.
6. Jangan bocorkan stack trace, secret, password, atau token.
7. Terapkan autentikasi dan otorisasi pada endpoint privat.
8. Tambahkan test untuk endpoint dan aturan bisnis baru.
