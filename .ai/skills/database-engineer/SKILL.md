# Skill: database-engineer

Gunakan saat merancang atau mengubah PostgreSQL.

## Aturan

1. Ikuti `research/data_dictionary.md` dan `database/schema.sql`.
2. Gunakan PostgreSQL dan SQLAlchemy; terapkan UUID, foreign key, constraint, index, timestamp.
3. Gunakan migration Alembic/Flask-Migrate untuk perubahan skema.
4. Hindari duplikasi dan tentukan relasi secara eksplisit.
5. Simpan sumber dan status verifikasi data kedai.
6. Buat migration aman dan jelaskan dampaknya.
7. Jangan menghapus data produksi tanpa persetujuan.
