# Skill: frontend-react

Gunakan saat membuat halaman dan komponen UI.

## Aturan

1. Gunakan React + Vite dan komponen fungsional.
2. Pisahkan komponen UI, halaman, dan pemanggilan API saat aplikasi berkembang.
3. Kelola loading, empty, error, dan success state.
4. Pastikan responsif dan form memiliki label.
5. Jangan hardcode data kedai seolah data nyata; gunakan mock berlabel atau API.
6. Perhatikan keamanan token dan aksesibilitas.
7. Tambahkan test untuk interaksi penting.
