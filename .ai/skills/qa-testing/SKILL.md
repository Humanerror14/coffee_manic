# Skill: qa-testing

Gunakan saat menguji fitur atau review kualitas.

## Aturan

1. Uji happy path, input tidak valid, data kosong, akses tanpa izin, dan error server.
2. Uji kombinasi filter, batas rating 1 dan 5, tolak nilai di luar rentang.
3. Pastikan pengguna tidak dapat mengubah data/admin tanpa otorisasi.
4. Periksa mobile, tablet, desktop, keyboard, dan pesan error.
5. Verifikasi provenance dan status data kedai.
6. Laporkan reproduksi, hasil aktual/harapan, severity, dan bukti.
7. Jangan menyatakan test lulus jika belum dijalankan.
